# RoseWare — immersive concept

An immersive 3D concept redesign for RoseWare Corporation (not the official site): one continuous Maldivian world,
from above the clouds to a coral-stone pavilion that holds the RoseWare stack, a server hall, a solar terrace, a map table
of project sites and a security shell over the island. The sky follows the real time in Malé.

- Live site: https://mooonreader.github.io/roseware-stack/
- Previous version: https://mooonreader.github.io/roseware-stack/v3/
- Skies and PBR textures: Poly Haven (CC0), fetched by `tools/fetch_assets.py`. Built with three.js.

# RoseWare concept: The Stack

Concept redesign of the RoseWare hero as an interactive, scroll-driven 3D infrastructure stack. Not the official RoseWare website.

Live: https://mooonreader.github.io/roseware-stack/


Satellite lagoon colours: contains modified Copernicus Sentinel data (2023–2026), via Earth Search / AWS Open Data (`tools/fetch_sat.py`).
